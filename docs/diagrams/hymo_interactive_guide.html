Overview

A configured hybrid model repeats [MLA + MoE, GDN, GDN, GDN] eight times. The 3:1 ratio describes this interleaving, not two sequential stacks. The approximately 30B-token training exposure is planned, not a completed-run claim.

Model

Configured width is 896 and vocabulary is 64,256. Each MLA layer uses latent KV rank 128 and MoE with 16 routed experts, top-2 selection and one shared expert. RoPE behavior is layer-specific. Training-only depth-2 MTP weights are 0.3 and 0.1. No fresh parameter count or MTP correctness certification is claimed.
