HyMo

A 434M-active / 1.13B-stored hybrid language model combining Gated Delta Networks (24 linear attention layers) with Multi-Head Latent Attention (8 full attention layers), Asymmetric Mixture-of-Experts, and NorMuon matrix optimization. Pretrained on 30B tokens.

Active Params: 434M per Token
Stored Params: 1.13B Parameters
Hybrid Ratio: 3:1 (24 GDN : 8 MLA)
MoE: 1 Shared + 8 Routed (Top-2)
Optimizers: NorMuon (2D) + AdamW (1D)
