HyMo

A configured 32-layer hybrid language model combining Gated Delta Networks (24 linear attention layers) with Multi-Head Latent Attention (8 full attention layers), Asymmetric Mixture-of-Experts, and NorMuon matrix optimization. The training schedule targets approximately 30B tokens of exposure, not a measured completed run.

Width: 896 configured
Vocabulary: 64,256 configured
Hybrid Ratio: 3:1 (24 GDN : 8 MLA)
MoE: 1 Shared + 16 Routed (Top-2)
Optimizers: NorMuon + AdamW partition

Recurrence evidence boundary
